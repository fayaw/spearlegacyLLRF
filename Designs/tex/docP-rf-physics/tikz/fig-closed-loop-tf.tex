% Closed-loop response T = G_OL/(1+G_OL) of the direct loop (eq:closed-loop), model of
% tab:robinson-model (625 ns delay, 2.5 MHz amplifier pole) with the RFP lead network of the
% RFgui loop models (zero 944 kHz, pole 2.39 MHz). Data: data/closed_loop_tf.dat
% (+-300 kHz, 1 kHz steps) and data/closed_loop_tf_zoom.dat (+-12 kHz, 50 Hz steps), written by
% spear3rf/scripts/docP_figures.py. Columns: f (kHz), then dB and phase (deg) for
%   low  : on tune, G = 0.875, proportional only (gain fitted at 20-22 mA with the integral path in the model)
%   lowi : the same with the integral path, the RFP lag network (f_i 2.93 kHz, leak 0.26 kHz, shared phase)
%   p500 : 500 mA, optimum detuning (-36.0 kHz), G = 1, proportional only
%   i500 : the same with the integral path
% Measured points: data/closed_loop_meas_022.dat (2 Oct 2026, 09:47, 22 mA, PHASE.C -20) and
% data/closed_loop_meas_497.dat (13:51, 497 mA, PHASE.C -20), columns f (kHz), db, ph (deg), T = -H, computed
% from the RAM dumps as the RFgui routine does, |f| <= 300 kHz, +-18.8 kHz left out; written by
% spear3rf/scripts/analyze_measure_direct.py, which also writes data/closed_loop_wl_497.dat: the 497 mA run
% fitted with the klystron's amplitude gain and AM/PM free and G, delay, Q_L held at the low-current values.
% Ranges: wide |T| -18.7..+0.1 dB (measured -22.9..-5.8), phase -145..+144 deg; zoom |T| -7.6..+0.2 dB,
% phase -46..+21 deg.
