\vspace{4mm}
\begin{keynote}
This document reverse-engineers the tuner control loop \emph{as deployed on
SPEAR3}, from the legacy \fpath{spear-rf-code-legacy/rfApp/} source tree. Two
things are easy to get wrong when reading it. First, the architecture is a
dual loop, but only the inner phase-regulation loop is active on SPEAR3: the
outer voltage loop is PEP-II inheritance and its phase offset is fixed at zero.
Second, the \textbf{AB 1746-HSTP1 is still the in-service controller}; the Galil
DMC-4143 is in development and goes online only when the LLRF upgrade completes.
\end{keynote}
