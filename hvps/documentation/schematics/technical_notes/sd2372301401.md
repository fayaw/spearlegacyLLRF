## 5. Obsolescence Note

Two device families on this board drive the upgrade decision to redesign it:

- **VR1, VR2 — VTL5C** opto-coupled variable resistors (photoresistor optocouplers). These are the components identified as obsolete in the PDR. Their resistance swings from **MΩ to kΩ**; response time is milliseconds to reach the low resistance but **≈ 150 ms to return** to the high resistance.
- **U3–U8, U21 — 4N32** optocouplers (turn-on 5 µs, turn-off 100 µs).
- **DC2 — MAD4030-B**, an obsolete 4.5 W DC-DC converter formerly made by Astec, since acquired by Artesyn.
- **D1–Dn — 1N3064** small-signal switching diodes, now obsolete. Digi-Key recommends the Vishay **1N4150**; Vishay lists the **BAW27** as the direct replacement.

Zener clamping voltages used on the board: **1N4728 = 3.3 V, 1N4740 = 10 V, 1N4742 = 12 V, 1N4747 = 20 V**.

Also present: **MC34074** quad op-amps (GBW 4.5 MHz), **OP77** precision op-amps (GBW 600 kHz), **INA114** (GBW 1 MHz, 10 GΩ input impedance) and **INA117** (±200 V common-mode, 800 kΩ differential input impedance, −3 dB bandwidth 300 kHz) amplifiers, **BUF634** output buffers, **CD4044B** quad R/S three-state latches, and **NMA1215** isolated DC-DC converters.

## 6. How the PLC Reference Actually Enters — resolved

**J4A is drawn as an output** (driven by U20), which makes the injection point of the PLC voltage reference ambiguous from the drawing alone. J. Sebek's circuit analysis settles it:

> The voltage reference set point is sourced from **Output 0 of the AB Slot-8 module** and is connected across **J4-1 and J4-7**. *"Note, however, that on the common regulator board schematic, the Reference Voltage is somewhat confusingly called the Positive Voltage Limit Command."*

So **J4-1 (= J4A, "+ EL1 / POS. VOLTAGE LIMIT COMMAND") is the reference voltage INPUT, not a limit output.** The label on the drawing is a misnomer. The reference enters the **negative** input of an INA117 difference amplifier, so that stage's output is a negative voltage.

### Complete signal path

| Signal | Path |
|---|---|
| Voltage reference (setpoint) | AB Slot-8 **Output 0** → **J4-1 / J4-7** |
| HV readback | Voltage dividers on WD-730-794-04-C0 → **J1A / J1B** → INA117 → OP77 error amplifier |
| Voltage monitor out | BUF634 → 1 kΩ → **J3-1** → AB Slot-8 **Input 0** |
| Current monitor out | BUF634 → **J3-2** → AB Slot-9 **In-1** |
| Current reference | Enerpro +5 V reference → **J4-2 (IL1)** |
| Control voltage out | Diode minimum-select → **J4-3 SIG-HI** → Enerpro SIG HI |

## 7. Control Architecture — minimum-select, not summing

The voltage and current chains are **not summed**. They are combined through a **non-linear diode junction with the two anodes tied together**: the *lower* cathode voltage wins and sets the common anode, which becomes SIG HI. A 15 V supply through 10 kΩ keeps the conducting diode biased; a **10 V Zener** clamps the anode.

> **The AC current loop never takes control.** Its reference at J4-2 comes from the Enerpro board's +5 V reference; against a typical current sense of ≈ 2.2 V DC the OP77 error amplifier saturates at ≈ +14 V, above the 10 V clamp, so the current chain can never win the select. Sebek: *"it probably is better to just eliminate this circuit which is designed to never be used in the feedback control of the Enerpro."* **The HVPS is voltage-regulated only.**

> **This board senses AC input current, not HVPS output current.** The phases are sensed by **300:5 current transformers** (EI-730-790-00-C0), full-wave rectified, paralleled, and terminated in a **0.5 Ω burden resistor** (WD-730-790-01-C3). HVPS *output* current is measured independently by the Danfysik transducer in the termination tank.

### Loop dynamics

| Element | Value |
|---|---|
| Voltage input low-pass | τ = 0.01 s ⇒ corner **15.9 Hz** |
| Error amplifier zero | **7.96 Hz** |
| Error amplifier poles | **0 Hz** (pure integrator) and **15.9 kHz** |
| System type | **Type 1** — no steady-state error |
| Integrator gain | ≈ **−5 × 10⁻³** |

### Trip thresholds

The over-voltage comparator is potentiometer-set from **2 V to 12 V**, i.e. **20 kV to 120 kV** of HVPS output. **The as-set values for over-voltage and over-current are not recorded anywhere in this repository** and should be measured at TP10 and TP11 and published.
