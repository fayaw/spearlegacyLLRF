## 2. Relationship to SD-730-793-04

This board and **SD-730-793-04-C2** share the same title and the same CAD file number base (73079304), but they are **two generations of the same function**:

| | SD-730-794-04-C0 | SD-730-793-04-C2 |
|---|---|---|
| Date | R. Cassel, 11/08/99 | M. Nguyen, 10-JUN-02 |
| CAD file | 73079304.**SCH** | 73079304.**DDB** |
| Logic rail | **+15 V** | +12 V |
| Opto input | **6N-138** | 6N-139 |
| Gate drivers | **Discrete complementary pairs** — Q3/Q4 IRFD9120 (P-ch) with Q5/Q6 IRFD110 (N-ch) | **MIC-4451** driver ICs |
| Logic family markings | CM-4049, CM14528, 4047B | CD4049, CD4538, CD4047B |
| Timing diagram | None on sheet | Present (50 ms / 5 ms / 44 µs / 3 × 5 µs) |
| Slave output | J1, J2, J3 (SIP2 / SIP4) | J1 SIP4 "Output Plug to Old Slave Trigger Bd" driven by MIC-4427 |
| Optical SCR note | Absent | Present ("used to drive the new optical SCR") |

> The phrase **"Old Slave Trigger Bd"** on the 2002 drawing most likely refers to boards of *this* 1999 vintage. When servicing a crowbar trigger board, establish which drawing applies to the board in hand before assuming component values.

## 5. Timing Chain

| Stage | Device | Timing components |
|---|---|---|
| Envelope astable | **U1 — 4047B** ("ASTBLE") | **R1 205 kΩ**, C13 0.1 µF, C23 0.01 µF → TP1 |
| Carrier astable | **U4 — 4047B** ("ASTBLE") | **R25 25 kΩ**, R2 24.9 kΩ, C2 200 pF, C11 0.1 µF → TP2 |
| Monostables | **U6A / U6B — CM14528** | R37, R38 **24.9 kΩ**; C1, C5 200 pF; C14 |
| Monostables | **U2A / U2B — CM14528** | R3, R4 **147 kΩ**; C4, C3 200 pF; C10 0.1 µF |
| Logic | **U3A–U3F — CM-4049** inverters | R12, R13 100 Ω |

Indicators: LED1 and LED3 (HLMP-1700), R16 2.2 kΩ, R20 2.2 kΩ. Test points TP1, TP2, TP4, TP5.

> Note that **R3/R4 = 147 kΩ** here, where the 2002 board uses 24.9 kΩ with a note to substitute 78.70 kΩ for conventional SCRs. The three values correspond to three different gate-pulse widths; they are **not** interchangeable between board generations.
