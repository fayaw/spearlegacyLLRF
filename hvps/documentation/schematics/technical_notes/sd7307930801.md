# SD-730-793-08 — SCR Control Driver, Left Side Trigger Interconnect Board

> **Verification status: VERIFIED.** Read directly from the scanned drawing on 3 September 2026 by rendering `hvps/documentation/schematics/sd7307930801.pdf` to image.
>
> **This drawing was previously mis-identified.** The superseded note described it as "Secondary rectifiers D1–D24", and `Designs/tex/L_legacy_system_architecture.pdf` cited it as the source for the secondary rectifier specification. It is neither — it is a **printed-circuit-board schematic for SCR trigger and interlock electronics**.
>
> This is the board J. Sebek refers to in `pps/HoffmanBoxPPSWiring.docx` as "the Left Side Trigger Interconnect Board, SD-730-793-08-C1", the destination of the Pearson CT-110 coaxial cable from the Termination Tank.

## 2. External Interfaces

### 2.1 Fiber-optic — all three HVPS fibers appear here or on the companion board

| Designator | Device | Function (as labelled) | Direction |
|---|---|---|---|
| J2 | HFBR-2412 | **"F.O KLYSTRON CROWBAR"** | receiver (in) |
| J3 | HFBR-1412 | **"F.O STATUS"** | transmitter (out) |

The third fiber, **F.O SCR ENABLE**, is received on J2 of the right-side board (SD-730-793-07). Between the two boards these are exactly the three fibers documented between the B118 Hoffman Box and the B514 power section: SCR ENABLE (in), CROWBAR (in), STATUS (out).

> Note that **STATUS is transmitted from this board** (HFBR-1412 is a transmitter). This corroborates the description of the HVPS STATUS fiber as originating in the B514 power section rather than in the B118 controller.

### 2.2 Coaxial

| Designator | Function (as labelled) |
|---|---|
| J1 (BNC) | **"KLYSTRON ARC TRIGGER"** |

Input protection on J1 as drawn: R1 510 Ω, D2 1.5KE7.5CA, D1 1.5KE12A, R4 51 Ω ½ W, C4 0.001 µF.

> This is the signal referred to elsewhere in the project documentation as the "KLYSTRON ARC TRIGGER (BNC-12)". Per Sebek, it is driven from a 3.333 mΩ (15 A = 50 mV) shunt in the HV return cable in the Termination Tank, wired via TS-6 terminals 20/21.

### 2.3 COMMANDS bus (P1, IDC14)

Labelled **"TO RIGHT-SIDED TRIG INTERCONNECT BOARD"**. Same named signals as the companion board: +12V PWR, 24V FAULT/ENABLE, FO SCR ENABLE, CB ENABLE, SLAVE CB TRIG, PLC FORCE CB, SLAVE CB OFF.

### 2.4 MONITORING bus (M1, IDC14)

Named signals: **SCR ENABLE MON, CB TRIG MON, CB MONITOR, KLYS ARC MON, SCR MONITOR, KLYS CB MON**.
