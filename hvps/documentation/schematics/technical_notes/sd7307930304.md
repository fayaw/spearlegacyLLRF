# SD-730-793-03 — 12 kV SCR Driver Board

> **Verification status: VERIFIED.** Read directly from the scanned drawing on 3 September 2026 by rendering `hvps/documentation/schematics/sd7307930304.pdf` to image. Text in quotation marks is transcribed literally.
>
> **This drawing was previously mis-catalogued** in this repository as "SCR stacks". It is not; it is a gate-driver board.

**Function**: generates the gate-drive pulse train for the 12 kV main rectifier SCRs. It takes a low-level trigger in on an opto-isolated input and delivers a high-current, transformer-isolated gate pulse burst.

## 2. Timing — from the drawing's own timing diagram

The drawing carries a timing diagram captioned *"with 60 Hz Trigger Input from The Test Box"*:

| Test point | Interval |
|---|---|
| **TP1** | **50 µs ± 5%** |
| **TP2** | **16 µs ± 1 µs (Adj by R2)** |
| **TP4 – TP5** | **5 µs**, **5 µs**, **18 µs ± 5%** |

> The 16 µs figure independently confirms Sebek's description of the HVPS gate drive as *"trigger pulses 16 µs long, in bursts spaced 15° apart"*, and the two supply rails on P1 confirm *"first at 240 V, then at 120 V"*.

## 3. Power Input — P1

Connector **P1 = 4DB-P107-06**:

| Pin | Signal |
|---|---|
| 1 | **+240 V** |
| 2 | **+120 V** |
| 3 | GND |
| 4 | +5 V |
| 5 | AC OUT |

HV power section: LED2 (MV 5474C) "HV PWR" indicator, R10 2 kΩ 11 W, D5 and D6 MR856 rectifiers, **F1 5 A**, **F2 1/8 A**. L1, L2, C16 and R23 are marked **N/U** (not used) — the components the C4 revision was raised to document.

## 6. Output Stage

| Item | Detail |
|---|---|
| Drivers | **U7, U8 — MIC-4451** |
| Switches | **Q1, Q2 — IXFH12N90** MOSFETs |
| Pulse transformer | **T1 — 60T / 60T / 60T**, taps 1A, 1B, 2A, 2B, 3A, 3B |
| Transient suppression | D1–D4 **1.5KE300A**; D8, D9 **1N4744** |
| Snubbing / storage | C6–C9 4.7 nF; **C18 3 µF 200 V** |
| Gate resistors | R7, R8 51 Ω ½ W; R5, R6 1.0 Ω; R14, R15 5.1 kΩ |
| Rail decoupling | C17, C19 10 µF; C20, C22 0.1 µF |

The 60:60:60 turns ratio gives a 1:1:1 isolated three-output pulse transformer, so one board services multiple series SCRs in a stack.
