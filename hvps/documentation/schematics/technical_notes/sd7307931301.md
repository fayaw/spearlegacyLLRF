# SD-730-793-13 — Optical SCR Trigger Board

> **Verification status: VERIFIED.** Read directly from the scanned drawing on 3 September 2026 by rendering `hvps/documentation/schematics/sd7307931301.pdf` to image.
>
> **This drawing was previously mis-identified.** The superseded note described it as "Crowbar SCRs (SCR13-16)", and `Designs/tex/L_legacy_system_architecture.pdf` cited it as the source for the crowbar thyristor specification. It is neither — it is the **Optical SCR Trigger Board**, the low-level electronics board that generates the gate pulse train for the thyristors.

## 2. Why This Board Matters

The power input connector **P1** is labelled with the rails that produce the thyristor gate pulses:

| P1 pin | Rail |
|---|---|
| 1 | **+240 V** |
| 2 | **+120 V** |
| 3 | GND |
| 4 | +5 V |
| 5–6 | AC OUT |

> This is direct hardware confirmation of the gate-pulse description in J. Sebek's HVPS hazards note: *"The HVPS controller sends trains of 16 µs pulses in 15° bursts to fire the thyristors in the phase control stacks. The amplitude of the first pulse is 240 V; the amplitudes of the later pulses are 120 V."* The two rails on P1 are exactly those two amplitudes.

Connector P1 is a 4DB-P107-06.

## 3. Signal Chain as Drawn

```
optical input ──► U5 (6N-139 optocoupler) ──► DRIVE
                                               │
                        U4 (CD4047B astable, 20–120 µs adjustable via R2 100K 12T)
                                               │
                        U6A/U6B, U2A/U2B (CD4538 dual monostables: 5 µs and 50 µs)
                                               │
                        U3A–U3F (CD4049 inverters)
                                               │
                        U7, U8 (MIC-4451 drivers) ──► Q1, Q2 (IXFH12N90 MOSFETs)
                                               │
                        T1 pulse transformer (60T / 60T / 60T)
                                               │
                                       gate pulse outputs
```

### 3.1 Timing (from the timing diagram on the drawing)

Test points TP1, TP2, TP3 are annotated with **50 µs**, **44 µs (Adj. by R2)** and **5 µs** pulse widths. Test points TP1–TP7 are provided.

## 5. Where the Actual Crowbar Thyristors Are Documented

The crowbar **power** assembly is not on this drawing. For it, see:

- `sd7307900101.pdf` (SD-730-790-01-C1) — labels the crowbar assembly "CROWBAR 40KV 80A" and shows it across the four series output stages
- PS-341-360-01 §5.3 — crowbar oil-to-oil bushings rated 100 kV DC, 80 kA peak
- `hvps/documentation/procedures/spear3HvpsHazards.tex` — each crowbar stack comprises six thyristors, each with a 5 MΩ voltage-sharing resistor (30 MΩ per stack)
- SLAC-PUB-7591 — the crowbar conducts approximately **10 µs** after triggering
