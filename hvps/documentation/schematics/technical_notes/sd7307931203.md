# SD-730-793-12 — 2MW Klystron PS Monitor Board

> **Verification status: VERIFIED.** Read directly from the scanned drawing on 3 September 2026 by rendering `hvps/documentation/schematics/sd7307931203.pdf` to image.
>
> **This drawing was previously mis-identified.** The superseded note described it as "Filter capacitors", and `Designs/tex/L_legacy_system_architecture.pdf` cited it as the source for the filter-capacitor specification. It is neither — it is the **PS Monitor Board**, the analog signal-conditioning board that produces the HVPS voltage and current monitor outputs.

## 2. The Two Monitor Scale Factors — Directly Labelled

This is the most operationally important content on the drawing, because it settles the HVPS divider ratio question from hardware:

| Output | Connector | Label on drawing |
|---|---|---|
| HVPS output voltage | **BNC1** | **"+ Voltage 10 kV/V"** |
| HVPS output current | **BNC2** | **"+ Current 5A/V"** |

The voltage-monitor input pin is correspondingly labelled **"−10 kV/V"** at P1A.

> **Consequence**: the end-to-end HVPS voltage monitor scaling is **10 kV per volt**, i.e. a ratio of **≈ 10,000:1**. This is independently consistent with the divider drawing WD-730-794-04-C0 (two chains of five 20 MΩ resistors into two 1 MΩ in parallel, the 500 kΩ bottom leg loaded by the regulator’s ≈ 10.5 kΩ input, giving 9.1 V at 91 kV) and with the June 2020 measured readback of 7.183 V at 72.08 kV (÷10,035).

## 3. Signal Chains as Drawn

### 3.1 PS Voltage Monitor #2

```
P1A ("−10 kV/V")  ──► R25 2k 12T pot ──► R26 9.09k ──► U4 INA117 ──► U6 INA117 ──► R8 1k ──► BNC1
P1B (V RTN)                                                                                 "+ Voltage 10 kV/V"
                                    (R27 marked N/U — not used)
```

### 3.2 PS Current Monitor

```
P1H (+5A/V)  ──► R24 150 ──► R13/R14/R15 100 ½W ──► U3 INA117 ──► U5 INA117 ──► R7 1k ──► BNC2
P1E (I RTN)                                                                               "+ Current 5A/V"
```

### 3.3 Reference voltage path

```
TB2 (TBLOCK-2, REF VOLTAGE) ──► U1 INA117 ──► U7 BUF634 ──► J2H / J2G
```

### 3.4 Crowbar input path

```
BNC3 (CROWBAR) ──► R31/R32 10k, R33 511 1%, R? 536 1%, R34 10k ──► U2 AD841 ──► R12 100 ──► U10 BUF634 ──► J2E / J2D
```

### 3.5 Additional buffered outputs

U8 and U9 (BUF634) drive J2C/J2B and J2A/J2I. TB1 (TBLOCK-4) carries outputs via R35/R36 1 kΩ.

## 4. Power Architecture

```
P1G (+15V) ─┐
P1F (−15V) ─┴─► D1/D2 1N4728 ──► L1 470 µH, C1 0.47 µF ──► DC1, DC2 (NMH2415S)
                                                            │
                                        two isolated ±15 V rails: ±15V1 (GND1), ±15V2 (GND2)
```

The two **NMH2415S** isolated DC-DC converters create two separate grounds, so the voltage and current monitor chains are galvanically isolated from each other. Decoupling capacitors C2–C21 are 0.47 µF.
