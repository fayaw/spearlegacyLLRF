# SD-730-793-07 — SCR Control Driver, Right Side Trigger Interconnect Board

> **Verification status: VERIFIED.** Read directly from the scanned drawing on 3 September 2026 by rendering `hvps/documentation/schematics/sd7307930702.pdf` to image.
>
> **This drawing was previously mis-identified.** The superseded note described it as "Filter inductors L1/L2", and `Designs/tex/L_legacy_system_architecture.pdf` cited it as the source for the filter-inductor specification. It is neither — it is a **printed-circuit-board schematic for SCR trigger and interlock electronics**. The entire `SD-730-793-xx` family are control/trigger boards, not power assemblies.

## 2. External Interfaces

### 2.1 Fiber-optic

| Designator | Device | Function (as labelled) |
|---|---|---|
| J2 | HFBR-2412 receiver | **"F.O SCR ENABLE"** |

This is the receiving end of the SCR ENABLE fiber that runs from B118 to the HVPS. Loss of light removes the SCR enable — the fail-safe convention described throughout the interlock documentation.

### 2.2 Coaxial

| Designator | Function (as labelled) |
|---|---|
| J1 (BNC) | **"TRANSFORMER ARC TRIGGER"** |

Input protection on J1 as drawn: R37 510 Ω, D9 1.5KE7.5CA, C30 0.001 µF, D8 1.5KE12A, R33 51 Ω ½ W.

> This is the signal referred to elsewhere in the project documentation as the "TRANSFORMER ARC TRIGGER (BNC-0)".

### 2.3 COMMANDS bus (P1, IDC14)

Labelled **"TO LEFT-SIDED TRIG INTERCONNECT BOARD"**. Named signals on the bus:

- +12V PWR
- 24V FAULT/ENABLE
- FO SCR ENABLE
- CB ENABLE
- SLAVE CB TRIG
- PLC FORCE CB
- SLAVE CB OFF

### 2.4 Other connectors

| Designator | Type | Function |
|---|---|---|
| E1 | IDC20 | SCR TRIGGERS |
| P5, P6, P7 (+3 more) | IDC10 | Trigger outputs ±A, ±B, ±C |
| M1 | IDC14 | MONITORING — XFMR ARC MON, SCR MONITOR, PLC CB MON |

## 4. Relationship to the Left Side Board

| | **Right side (this board, -07)** | **Left side (-08)** |
|---|---|---|
| BNC arc input | TRANSFORMER ARC TRIGGER | KLYSTRON ARC TRIGGER |
| Fiber receiver | F.O SCR ENABLE | F.O KLYSTRON CROWBAR |
| Fiber transmitter | — | F.O STATUS |
| COMMANDS bus | to left-side board | to right-side board |

Together the two boards account for exactly the **three fibers** documented between B118 and B514: SCR ENABLE (in), CROWBAR (in), STATUS (out).
