This tank sits in B132 near the klystron. It is the interface between the HV cable from B514 and the klystron, and it houses the grounding switch, the current sensors and the cable-termination network.

## 3. Cable Termination Network — as drawn

```
HVT-1 ──┬── L1 "350 UHY 40A" ──┬── L2 "350 UHY 40A" ──┬──────────┬──► HVT-2 (LOAD)
        │        ║             │        ║             │          │
        └── D1 "25KV 100A" ────┘── D1 "25KV 100A" ────┘          │
        │        ║             │        ║                        │
        └── C3 "30 NFD 37KV" ──┴── C4 "30 NFD 37KV" ─┘           │
                                                      │          │
                                          C1 "10 NFD 56KV"    CT1 (Pearson)
                                                      │
                                          C2 "10 NFD 56KV"
                                                      │
                                          R1 "50 OHM 90KV"
                                                      │
                                                    GND
```

| Reference | Value as drawn | Function |
|---|---|---|
| **L1, L2** | **"350 UHY 40A"** | Cable termination inductors — limit rate of rise of cable discharge current into the klystron |
| D1 (×2) | "25KV 100A" | Diode across each inductor |
| C3, C4 | "30 NFD 37KV" | Capacitor across each inductor |
| C1, C2 | "10 NFD 56KV" | Series pair to ground |
| R1 | "50 OHM 90KV" | Series damping resistor to ground |

> **Design figure vs. as-built.** SLAC-PUB-7591 (Cassel & Nguyen, 1997) describes "small **200 µhy** inductors in the termination tank". The as-built SPEAR3 drawing labels them **350 µH**. The 200 µH figure is the PEP-II design value; 350 µH is what is installed.
>
> Note also that these are designated **L1 and L2 on this drawing**, the same designators used for the HVPS *primary filter* inductors on SD-730-790-01. Some documents call the termination pair "L3/L4"; that designation does not appear on either drawing.

## 4. Current Sensors

| Designator | Device | Label on drawing | Purpose |
|---|---|---|---|
| **CT1** | Pearson current transformer | **"10A/V PERSON 110"** | Wide-bandwidth CT. Its coaxial output monitors the HV cable for the fast transients that indicate a klystron arc, and feeds J1 of the Left Side Trigger Interconnect Board (SD-730-793-08-C1) to initiate a crowbar trigger. |
| **CT2** | Danfysik DC-CT | **"DANFYSIK DC-CT"**, "+OUT FOR POS CURRENT" | DC current transducer measuring klystron cathode current. Pin functions labelled on the drawing: test, status −, GRN, DC PWR, −15 V, +15 V, output, + status. |
| **S1** | Shunt | **"15A/50MV SHUNT"** | Measures current in the HV return cable. 15 A = 50 mV ⇒ **3.333 mΩ**. Wired out via TS-6 terminals 20/21 to BNC-12, serving as the klystron arc trigger. |

> Both Sebek's PPS wiring note and this drawing agree on the Pearson 110 (10 A/V) and the 15 A / 50 mV shunt.

## 5. Grounding Switches

| Designator | Label | Contacts as drawn |
|---|---|---|
| **SW1** | "MANUAL GRN SW" | NC / COM / NO |
| **SW2** | "ROSS-GRN-SW" (HV) | Coil plus contacts numbered 1–5 |

Wire colours shown on the switch wiring: GRN, WHT, WHT, RED, ORG, YEL, BLU.

The terminal block at the right of the drawing is numbered 1–5 with colours: 1 WHT, 2 WHT, 3 RED, 4 ORG, 5 YEL.

> **Open item (unchanged)**: the documentation is inconsistent on whether the manual grounding ("mushroom") switch auxiliary contact monitored by the PLC is NO or NC. WD-730-794-06-C0 shows NO; this drawing shows SW1 with both NC and NO contacts available. Field verification is still required — see `Designs/tex/L_legacy_system_architecture.pdf` §20.2 G2.
