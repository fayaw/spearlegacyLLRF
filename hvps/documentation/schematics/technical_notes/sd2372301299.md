## 2. Connectors — the definitive J5 / J7 answer

The drawing's numbered notes settle a question the derived documentation had been inconsistent about:

| Connector | Role (per drawing notes) |
|---|---|
| **J5** | **Off-board phase references.** Note 10: *"FOR OFF-BOARD PHASE REFERENCES: INSTALL R37-R39 AND J5. OMIT R31-R33 AND T1."* This is the path used at SPEAR3. |
| **J7** | **Test** reference inputs (Note 11). |
| **J8** | Cable to the **FCOAUX60** auxiliary board. Note 12: *"FOR GATING PARALLELED SCRs CONNECT FCOAUX60 AUXILIARY BOARD VIA CABLE TO J8"*. |
| **J10** | 50/60 Hz jack (added at Rev J). |
| **J1 / P1** | Gate drive **+A, +B, +C GATE** — line-to-load SCRs |
| **J2 / P2** | Gate drive **−A, −B, −C GATE** — load-to-line SCRs |
| **J3 / P3** | SIG HI control input |
| **J6 / P6** | Includes the **EL** and **EN** limit inputs, driven from the regulator board (SD-237-230-14, outputs J4A "+EL1" and J4B "+IL1") |

Per Sebek's field trace, the three phase references land on **J5-1 (R37, phase A), J5-3 (R38, phase B) and J5-5 (R39, phase C)**.

## 3. Phase Reference Resistors — standard vs. SLAC

| Source | R37 / R38 / R39 |
|---|---|
| **This drawing's parts list** | **1.9 MΩ, ½ W, 1%, RN70** (R31–R39 are specified together) |
| **As installed at SLAC** | **200 kΩ** — per J. Sebek, `enerproBoardHvps.docx`, who works the Thevenin equivalent using 200.5 kΩ (200 kΩ plus the 500 Ω source impedance of the monitor winding) |

Both are correct in context. The Enerpro standard value assumes a line-voltage reference; the SPEAR3 references come from **monitor windings on the phase-shifting transformer legs** at only ≈190 V peak-to-peak, so a proportionally smaller resistor is required to deliver the same detector current. **Do not interchange these values.**

R41–R65 are ¼ W 1% RN60.

## 6. SIG HI Input Path

The control input **SIG HI** is buffered by **U6** (LM324) with:

| Ref | Value / role |
|---|---|
| R49 | 47.5 kΩ — holds the inverting input at +5 V DC |
| R50 | 100 kΩ |
| R51 | 1 kΩ |
| R42 | **SPAN** adjustment |
| R43 | **BIAS** adjustment |
| R52 | Range-setting resistor — see Note 18 |

**Note 18** (verbatim): *"R52 = 150K FOR 0V < SIG HI < 5.0V; R52 = 249K FOR .9V < SIG HI < 5.9V"*

**Note 1** (verbatim): *"FOR CURRENT SIGNAL INPUT SELECT R41 TO GIVE SIG HI +5.0VDC WITH MAXIMUM SIGNAL CURRENT"*

Other adjustments called out in the notes: **R42** gate delay span, **R43** gate delay bias, **R44** soft-start time, **R45** soft-stop time.

> At SPEAR3, SIG HI is the **sum** of a PLC feedforward term and a weighted analog-regulator error term — a summing arrangement, not a cascade. The regulator's contribution arrives from SD-237-230-14 output J4C, labelled "SCR PHASED-CONTROL OUTPUT / SIG-HI".

## 7. Upgrade Context

The LLRF upgrade replaces the FCOG6100 with an **FCOG1200 Rev L**. Two consequences follow directly from this drawing:

1. The FCOG1200 has no place for input resistors between J7 and the phase-detection circuitry, so a **phase reference adapter board** is required: three inputs, six resistors, six outputs — 3 × 576 kΩ to J7 pins 1–3 and 3 × 200 kΩ to J7 pins 4–6. Mating connector Enerpro C2MTAPLG08 = TE 3-640440-8; cover C2MTACVR08; crimp tool TE 58074-1.
2. Enerpro replaces **RN4A–C with 66.5 kΩ**, **RN4D–F with 287 kΩ**, and **C17–C22 with 0.033 µF**, so that one reference triplet is advanced and the other retarded by 15°.

**None of this adapter hardware exists in the installed legacy system.**
